# Responsible Use

CLAYは実験的な基盤です。利用・改変・連携・配布にあたっては、適用される法律、規則、プラットフォームの利用条件、組織内規程、倫理的な配慮、他者の権利を尊重してください。

## 基本的なお願い

- 違法行為や他者の権利侵害を目的として使用しないでください。
- 他人をだます、脅す、嫌がらせをする、プライバシーを侵害する、迷惑をかけるために利用しないでください。
- 人や組織に重大な影響を与える判断では、LLMの出力だけに依存せず、必要な専門家・一次情報・実際の確認を用いてください。
- 医療、法律、金融、雇用、安全などの領域では、適切な専門的判断と責任の所在を維持してください。
- 個人情報・機密情報の取り扱いは `PRIVACY_AND_DATA_HANDLING.md` に従って慎重に行ってください。
- 未検証の改変版やモジュールを、安全性・正確性が確認済みであるかのように表示しないでください。
- 外部ツールやエージェントAIと接続する場合は、権限、実行内容、承認、失敗時の影響を事前に確認してください。

## CLAYの姿勢

CLAYは人の仕事や判断を機械的に置き換えることだけを目的にしていません。人の能力を補い、考える余地を広げ、生活や活動を少しでも豊かにする使い方を探ります。

**できるだけ人に害を与えず、他者を尊重し、少しでも幸運を振りまくような使い方をしてもらえたら嬉しいです。**
