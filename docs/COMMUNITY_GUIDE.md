# CLAY Community Guide

## 1. 参加について

CLAYは、一人の開発者がすべての利用環境・モデル・用途を検証し、すべての特化版を実装することを前提としていません。汎用的な基盤を公開し、利用者や開発者がそれぞれの環境で試し、発見したことを共有しながら発展させることを目指します。

利用者は、CLAYの想定外の使い方を試しても構いません。独自の思考回路、専門モジュール、ワークフロー、アダプター、連携方法を作ることも歓迎します。公式の汎用基盤にすべて取り込む必要はありません。独立した実装や派生プロジェクトとして育てる選択肢もあります。

## 2. 開発環境と検証上の制約

開発者が現在利用できる環境には制限があります。公開時点の自己申告として、次の条件を共有します。

- **スマートフォン:** OPPO A5。高負荷なローカルLLMや大きな処理を使った検証には限界があります。
- **PC:** 高性能環境ではなく、実行・検証できる範囲に制限があります。詳細な機種・仕様を保証するものではありません。
- **LLM利用環境:** ChatGPTを主な開発・確認対象としています。開発者が利用できるプランは、準備時点で月額約1,500円程度の範囲です。プラン名・料金は変更されるため、公開時に必要なら再確認してください。
- **未経験・未検証の環境:** 高性能な有料モデルや上位プラン、ローカルLLM、エージェントAI、スマートグラス等を使った実環境の検証は十分にできていません。Astra、Fable、Grokの高性能モードなども、開発者自身が十分に触れていない例として挙げています。名称・提供状況は変化する可能性があります。

この制約を隠すのではなく、該当環境を使える方に独立して試してもらえたらと考えています。

## 3. 協力をお願いしたいこと

- ChatGPT以外のLLMで、読み込み・指示解釈・長い対話・パーソナライズを試す。
- Claude、Gemini、Grokなど、利用可能なモデルやプランで互換性を確認する。
- ローカルLLMやエージェントAI環境での利用可能性を調べる。
- スマートグラス、音声、センサー、外部ツールなどとの接続案を試す。
- Basic、ICC、DASなど、個別モジュールやワークフローの使い勝手・境界を検証する。
- 想定外の挙動、矛盾、分かりにくさ、導入の障壁を報告する。
- プロンプト、コード、設定、アダプター、独自モジュールによる改良を試す。
- 再現可能なテストケース、改善案、利用例を共有する。

これらは協力をお願いしたい例であり、特定の作業を依頼・強制するものではありません。

## 4. フィードバックの方法

連絡窓口やコミュニティの運用は、公開後の反応を見ながら決めます。現時点で毎日の確認や迅速な返信を約束するものではありません。

利用可能な場合は、GitHubのIssues / Discussionsや、開発者が案内するOpenAI Community上の投稿などを候補にします。公開窓口が確定するまでは、実在しない連絡先や対応時間を想定しないでください。

フィードバックには、次の情報があると検証しやすくなります。

1. 使用したCLAYのバージョン・ファイル構成。
2. 使用したLLM・プラン・モデル名・利用日。
3. 端末・OS・実行環境（分かる範囲）。
4. 期待した動作と実際の動作。
5. 再現手順・最小限の入力例。
6. 影響範囲、回避策、再現頻度。
7. その環境で未確認のこと。

**個人情報、患者情報、アカウント識別情報、秘密鍵、パスワード、APIキー、第三者の機密情報をフィードバックに含めないでください。** 提出前に必ず匿名化・マスキングしてください。詳しくは `PRIVACY_AND_DATA_HANDLING.md` を参照してください。

## 5. 改変版・派生版について

CLAYは独自の改変や拡張を歓迎する方向ですが、改変・再配布の許諾条件は、リポジトリ直下の現行 `LICENSE` が定めます。今回検討している将来の方針（改変版の明示、第三者への再配布の事前許可など）は、現行ライセンスにまだ反映されていません。必ず `LICENSE` と `LICENSE_POLICY_JA.md` の状態を確認してください。

将来、再配布が許可される場合には、少なくとも次を明記する方針を検討しています。

- 「改変版」または「派生版」であること。
- 元となったCLAYのバージョン。
- 変更点と変更者（本名の公開は必須としない）。
- 公式版ではないこと。
- 独立した検証状況と既知の制約。

## 6. 貢献・紹介・支援

開発者紹介や実名の公開は必須ではありません。寄付や支援も任意です。

商用利用を希望する組織・開発者には、将来的に個別の商用ライセンスを検討する可能性があります。収益の一部をプロジェクトに還元してもらう案もありますが、料率・条件・窓口は未決定であり、現時点で契約や許諾を意味しません。

## 7. 開発者からのお願い

開発者一人では確認できない部分が多くあります。利用できる環境や専門知識を持つ方に、できる範囲で一緒に試してもらえたら嬉しいです。自分では実装できない部分を他の方にお願いする、少し身勝手な呼びかけであることは承知しています。参加は無理のない範囲で構いません。

CLAYの思想に賛同する必要はありません。価値を見つけた人も、欠陥を指摘した人も、異なる使い方を発見した人も歓迎します。
